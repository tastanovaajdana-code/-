# Деплой на Vercel

Проект использует PostgreSQL (для продакшена) — SQLite подходит только для
локальной разработки, потому что у serverless-функций Vercel нет постоянного
диска. Ниже — пошаговая инструкция без необходимости давать кому-либо доступ
к вашим аккаунтам.

## 1. Создайте бесплатную базу PostgreSQL

Проще всего через [Neon](https://neon.tech) (есть бесплатный тариф):

1. Зарегистрируйтесь / войдите на neon.tech.
2. Create Project → выберите любой регион.
3. Скопируйте **Connection string** (вид
   `postgresql://user:password@host/dbname?sslmode=require`).

(Подойдёт любой другой Postgres-хостинг — Supabase, Vercel Postgres и т.д.)

## 2. Создайте проект на Vercel

1. Зайдите на [vercel.com](https://vercel.com) → **Add New → Project**.
2. Выберите **Import Git Repository** и подключите этот репозиторий
   (`tastanovaajdana-code/-`), ветка `claude/ort-testing-site-structure-us7ivs`
   (или заранее смёржите её в основную ветку).
3. **Важно:** приложение находится в подпапке `app/`, а не в корне репозитория.
   В настройках проекта (Project Settings → General → **Root Directory**)
   укажите `app`.
4. Framework Preset определится автоматически как **Next.js** — ничего менять
   не нужно.

## 3. Переменные окружения

В Project Settings → **Environment Variables** добавьте (для Production и
Preview):

| Имя | Значение |
|---|---|
| `DATABASE_URL` | строка подключения из шага 1 |
| `ADMIN_SESSION_SECRET` | любая длинная случайная строка (например, сгенерированная командой `openssl rand -hex 32`) |

## 4. Деплой

Нажмите **Deploy**. Vercel выполнит `npm install`, затем команду из
`package.json` → `"build": "prisma generate && prisma migrate deploy && next build"`,
которая создаст все таблицы в вашей базе автоматически.

## 5. Первичное сидирование (админ + пробный тест)

Миграция создаёт только структуру таблиц — начальные данные (админ и пробный
тест) нужно засеять один раз. Проще всего с локальной машины:

```bash
cd app
npm install
DATABASE_URL="<та же строка подключения из шага 1>" npm run db:seed
```

Появится:

```
Админ создан: логин "admin", пароль "admin123"
Пробный тест с 4 разделами и вопросами создан
```

Смените пароль/логин через переменные `SEED_ADMIN_LOGIN` /
`SEED_ADMIN_PASSWORD` при повторном запуске, либо просто поменяйте пароль в
базе после первого входа.

## 6. Готово

Откройте выданный Vercel URL (например `https://ваш-проект.vercel.app`):

- `/` — форма для ученика
- `/admin/login` — вход администратора (логин/пароль из шага 5)

## Дальнейшие деплои

Любой новый `git push` в подключённую ветку автоматически пересобирает и
обновляет сайт на Vercel — миграции применяются на каждом билде, данные не
теряются.
