# Платформа для тестирования по ОРТ (Кыргызстан, 11 класс)

Документ описывает структуру сайта (для ученика и администратора) и содержит
готовый промт, который можно использовать для генерации/разработки платформы
(например, отдать его Claude Code, другой AI-модели или разработчику как
техническое задание).

---

## 1. Общая концепция

Сайт предназначен для проведения тренировочного/официального тестирования по
ОРТ (Общереспубликанское тестирование) среди учеников 11 классов. Тест состоит
из **4 разделов** (пример для ОРТ: Аналогии, Математика, Чтение и понимание
текста, Грамотность письма — названия и состав разделов задаются админом).

Два типа пользователей:

- **Ученик** — проходит тест, не требует регистрации/пароля.
- **Администратор** — создаёт тесты, вопросы, назначает баллы, смотрит
  статистику всех учеников.

## 2. Структура для ученика (User Flow)

```
[1] Стартовая страница
    ├─ Поле "ФИО"
    ├─ Поле/выбор "Группа"
    └─ Кнопка "Начать тестирование"
        │
        ▼
[2] Страница теста
    ├─ Название теста (например "ОРТ — пробный тест №1")
    └─ 4 карточки разделов:
         ├─ Раздел 1: Аналогии       [статус: не начат / пройден]
         ├─ Раздел 2: Математика     [статус: ...]
         ├─ Раздел 3: Чтение текста  [статус: ...]
         └─ Раздел 4: Грамотность    [статус: ...]
        │ (клик по разделу)
        ▼
[3] Прохождение раздела
    ├─ Таймер раздела (обратный отсчёт, автозавершение по истечении)
    ├─ Вопрос N из M (навигация вперёд/назад, список вопросов сбоку)
    ├─ Варианты ответа (один/несколько верных) или поле для ввода ответа
    └─ Кнопка "Завершить раздел" / автозавершение по таймеру
        │ (после завершения всех 4 разделов)
        ▼
[4] Страница результатов
    ├─ По каждому разделу:
    │    ├─ Правильных ответов: X из Y
    │    └─ Баллы за раздел (по настройке админа)
    └─ Итоговый балл = сумма баллов по всем 4 разделам
```

### Детали

- Ученик вводит **ФИО** и **группу** один раз перед началом теста; эти данные
  привязываются к результату (не требуется пароль/логин).
- Список разделов виден сразу, ученик выбирает порядок прохождения (или админ
  может закрепить последовательный порядок — настраиваемо).
- У каждого раздела свой таймер (например, задаётся в минутах в настройках
  теста). По истечении времени раздел автоматически завершается и сохраняются
  введённые на тот момент ответы.
- После прохождения всех разделов — итоговая статистика: разбивка по разделам
  (правильные ответы + баллы) и общий суммарный балл по всем 4 разделам.

## 3. Структура для администратора (Admin Flow)

```
[1] Вход администратора (логин/пароль)
        │
        ▼
[2] Дашборд — общая статистика
    ├─ Таблица результатов: ФИО | Группа | Тест | Балл по каждому разделу | Итог | Дата
    ├─ Фильтр по группам / по тесту / по дате
    └─ Экспорт в Excel/CSV
        │
        ▼
[3] Управление тестами
    ├─ Создать/редактировать тест (название, описание)
    └─ Разделы теста (название, время на раздел, максимальный балл раздела)
        │
        ▼
[4] Управление вопросами
    ├─ Добавить вопрос вручную (текст, варианты, правильный ответ, балл)
    ├─ Загрузить вопросы файлом (Excel/CSV/Word/JSON — см. раздел 6)
    └─ Редактировать/удалять вопросы, распределять по разделам
        │
        ▼
[5] Настройка баллов
    ├─ Балл за вопрос (вес) — задаётся индивидуально или одинаково для раздела
    └─ Максимальный балл раздела / формула перевода (правильные → баллы)
        │
        ▼
[6] Управление группами
    └─ Создание списка групп, к которым привязываются ученики при старте теста
```

### Детали

- Админ может назначать **баллы за каждый вопрос отдельно** либо **общий
  максимум баллов на раздел**, а система распределяет баллы пропорционально
  правильным ответам (например: раздел из 20 вопросов = максимум 25 баллов →
  1 правильный ответ = 1.25 балла).
- Статистика на дашборде группируется по группам, чтобы учитель мог посмотреть
  результаты конкретного класса/группы.
- Импорт вопросов поддерживает несколько форматов, чтобы учителя могли
  использовать уже готовые файлы с вопросами.

## 4. Модель данных (сущности)

| Сущность | Поля |
|---|---|
| **Group** (Группа) | id, name |
| **Test** (Тест) | id, title, description, is_active |
| **Section** (Раздел) | id, test_id, title, order, time_limit_minutes, max_score |
| **Question** (Вопрос) | id, section_id, text, type (single / multiple / text), options[], correct_answer, points |
| **Attempt** (Попытка ученика) | id, student_fio, group_id, test_id, started_at, finished_at, total_score |
| **AttemptSectionResult** (Результат по разделу) | id, attempt_id, section_id, correct_count, total_questions, score, time_spent |
| **AdminUser** (Администратор) | id, login, password_hash |

---

## 5. Экраны (кратко)

1. `/` — форма ФИО + группа
2. `/test/:testId` — список разделов теста
3. `/test/:testId/section/:sectionId` — прохождение раздела с таймером
4. `/test/:testId/results/:attemptId` — итоговая статистика ученика
5. `/admin/login` — вход администратора
6. `/admin/dashboard` — сводная таблица результатов (фильтр по группам)
7. `/admin/tests` — список/создание тестов и разделов
8. `/admin/tests/:testId/questions` — управление вопросами (ручной ввод + загрузка файла)
9. `/admin/groups` — управление группами

---

## 6. Формат импорта вопросов (шаблон для Excel/CSV)

| section | question_text | type | option_a | option_b | option_c | option_d | correct_answer | points |
|---|---|---|---|---|---|---|---|---|
| Математика | Найдите значение выражения... | single | 12 | 15 | 18 | 20 | option_b | 1 |

- Поддерживаемые форматы загрузки: **.xlsx, .csv, .json** (опционально .docx
  с последующим парсингом текста).
- `type`: `single` (один верный вариант), `multiple` (несколько верных),
  `text` (ответ вводится текстом/числом).
- `correct_answer`: для `multiple` — список через запятую (`option_a,option_c`).

## 7. Рекомендуемый стек технологий

- **Frontend**: React (Next.js) + TypeScript, Tailwind CSS
- **Backend**: Next.js API routes (или отдельный Node.js/Express сервер)
- **База данных**: PostgreSQL (через Prisma) — либо Firebase/Firestore для
  быстрого старта без своего сервера
- **Хранение файлов вопросов**: обработка загрузки на сервере (библиотека
  `xlsx`/`papaparse` для парсинга Excel/CSV)
- **Авторизация администратора**: простая сессия/JWT, без публичной регистрации
- **Хостинг**: Vercel (frontend+API) + управляемая БД (Neon/Supabase) либо Firebase Hosting

## 8. Готовый промт для генерации сайта

Ниже — промт, который можно целиком скопировать и отдать AI-инструменту
(Claude Code и т.п.) или разработчику как техническое задание на реализацию.

> Разработай веб-платформу для проведения тестирования по ОРТ (Общереспубликанское тестирование, 11 класс, Кыргызстан) со следующими требованиями.
>
> **Стек**: React (Next.js) + TypeScript на фронтенде, Next.js API routes на бэкенде, PostgreSQL (через Prisma) для хранения данных. Стилизация — Tailwind CSS. Дизайн простой, чистый, адаптивный (мобильные устройства и десктоп).
>
> **Часть 1 — интерфейс ученика (без регистрации/пароля):**
> 1. Стартовая страница с формой из двух полей: «ФИО» и «Группа» (группа выбирается из списка, заданного админом, либо вводится вручную, если группы ещё нет). После заполнения — переход к тесту.
> 2. Страница теста: показывает название теста и список из 4 разделов в виде карточек (название раздела, количество вопросов, лимит времени, статус — «не начат» / «завершён»). Клик по карточке открывает раздел.
> 3. Страница прохождения раздела: обратный таймер (например 20–40 минут, задаётся в настройках раздела), вопросы (тип — один правильный ответ, несколько правильных, или текстовый ответ), навигация между вопросами, кнопка «Завершить раздел». При истечении таймера раздел завершается автоматически с сохранением текущих ответов.
> 4. Страница результатов: после прохождения всех 4 разделов показывает по каждому разделу количество правильных ответов из общего числа и набранные баллы (баллы рассчитываются по формуле/весам, заданным администратором), а также итоговый суммарный балл по всем 4 разделам.
>
> **Часть 2 — панель администратора (защищена логином/паролем):**
> 1. Вход администратора.
> 2. Дашборд со сводной таблицей результатов всех учеников: ФИО, группа, тест, баллы по каждому разделу, итоговый балл, дата прохождения; с фильтром по группам и тестам, и экспортом в Excel/CSV.
> 3. Раздел «Тесты»: создание тестов, создание/редактирование разделов теста (название, лимит времени, максимальный балл раздела).
> 4. Раздел «Вопросы»: возможность добавить вопрос вручную (текст, варианты ответа, правильный ответ, тип вопроса, балл за вопрос) и возможность загрузить вопросы файлом (поддержка форматов .xlsx, .csv, .json по заданному шаблону колонок: section, question_text, type, option_a-d, correct_answer, points) — с валидацией и предпросмотром перед сохранением.
> 5. Возможность назначить балл каждому разделу — либо весом на каждый вопрос, либо максимальным баллом на раздел с автоматическим пропорциональным распределением по количеству правильных ответов.
> 6. Раздел «Группы»: создание и редактирование списка групп учеников.
>
> **Модель данных**: Group, Test, Section, Question (с вариантами ответа и весом/баллом), Attempt (попытка ученика: ФИО, группа, тест, время начала/конца, итоговый балл), AttemptSectionResult (результат ученика по каждому разделу: правильные ответы, балл, время).
>
> **Дополнительно**: реализовать серверную валидацию таймера (чтобы время нельзя было обойти на клиенте), сохранение прогресса при разрыве соединения, адаптивную вёрстку, локализацию интерфейса на русском языке.
